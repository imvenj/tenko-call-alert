Tenko 点呼アラート
=================

Tenko の点呼一覧ページを監視し、新しい点呼が入ったときに音声でお知らせする Chrome 拡張機能です。

通知音声には Chrome に標準搭載されている TTS（音声読み上げ）機能を使用します。音声ファイルの準備や外部サービスの設定は必要ありません。


主な機能
--------

- 新しい点呼を検出すると、音声でお知らせします。
- 音声通知の回数と読み上げ速度を変更できます。
- 点呼が未対応の間、一定の間隔で音声通知を繰り返せます。
- 点呼一覧ページを開き忘れている場合、デスクトップ通知でお知らせできます。
- 別のタブを表示しているときも、点呼一覧ページの監視を継続できます。
- 拡張機能のアイコンで、点呼一覧ページの監視状態を確認できます。


インストール方法
----------------

1. ZIP ファイルを展開します。
2. Chrome のアドレスバーに「chrome://extensions/」と入力して、拡張機能の管理画面を開きます。
3. 画面右上の「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
5. 展開した拡張機能のフォルダーを選択します。


使い方
------

1. Chrome で Tenko にログインします。
2. 点呼一覧ページを開きます。
3. 拡張機能のアイコンに緑色の「✓」が表示されていることを確認します。
4. 新しい点呼が入ると、「点呼があります。速やかに対応してください。」と音声でお知らせします。

拡張機能のアイコンをクリックすると、監視や通知に関する設定を変更できます。


アイコンの表示
--------------

- 緑色の「✓」：点呼一覧ページを監視しています。
- 赤色の「!」：Tenko または点呼一覧ページが開かれていません。


設定項目
--------

監視を有効にする
  新しい点呼の検出と音声通知を有効または無効にします。
  初期設定は「有効」です。

バックグラウンド監視
  点呼一覧ページが別のタブやウィンドウの背後にある場合でも、監視が止まりにくくなるようにします。
  安定して点呼を検出するため、通常は有効のまま使用することをおすすめします。
  初期設定は「有効」です。

音声通知の回数
  新しい点呼を検出したときに、通知音声を読み上げる回数を設定します。
  1～5 回から選択できます。初期設定は「1 回」です。

音声の再生速度
  Chrome の TTS 機能による読み上げ速度を設定します。
  0.5～2.0 倍から選択できます。初期設定は「1.0 倍」です。

未対応の間は音声通知を続ける
  点呼が未対応の間、音声通知を繰り返します。対応が完了すると通知は自動的に停止します。
  初期設定は「有効」です。

繰り返し間隔
  未対応の点呼について、音声通知を繰り返す間隔を秒単位で設定します。
  5 秒以上で指定できます。初期設定は「15 秒」です。

音声をテスト
  現在設定されている回数と再生速度で、通知音声を試聴します。

点呼一覧ページの表示忘れを通知
  Tenko または点呼一覧ページが開かれていない場合に、デスクトップ通知を表示します。
  通知をクリックすると、点呼一覧ページが開きます。
  初期設定は「無効」です。

表示忘れの通知間隔
  点呼一覧ページが開かれていないことを確認し、デスクトップ通知でお知らせする間隔を設定します。
  1～60 分で指定できます。初期設定は「3 分」です。


ご利用時の注意
--------------

- 本拡張機能は、Chrome で Tenko の点呼一覧ページを開いているときに動作します。
- ページを開いた時点ですでに存在する点呼については通知しません。監視開始後に新しい点呼が入った場合に通知します。
- 音声が聞こえない場合は、パソコンの音量と Chrome の音声出力をご確認ください。また、「音声をテスト」ボタンで通知音声を確認できます。
- 確実に通知を受け取るため、点呼一覧ページを開いたままにし、「バックグラウンド監視」を有効にしてください。
